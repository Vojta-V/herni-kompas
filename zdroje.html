02 / OBRÁZKY A VZHLED

Vlastní pixelové světy

Tři tematické obrázky — stavění, farma a jeskyně — vznikly jako originální SVG ilustrace napsané s pomocí OpenAI Codex. Nejsou to screenshoty, oficiální grafika ani přesná zobrazení prostředí uvedených her.

Web používá systémová písma a společný soubor style.css. Filtr a volba nálady fungují lokálně pomocí script.js.

03 / CITACE POUŽITÉ AI

OpenAI Codex

AI pomohla zvolit herní téma, navrhnout světlý vzhled, napsat HTML, CSS a JavaScript, vytvořit SVG ilustrace a rozdělit skutečnou práci do postupných commitů. Datum tvorby: 5. listopadu 2026.

Hlavní pokyny — shrnutí zadání

  • Vytvořit samostatný vícestránkový web s odlišným tématem a vizuálním stylem.
  • Propojit stránky menu, použít externí CSS a nejméně tři tematické obrázky.
  • Uvést internetové zdroje, použitou AI a prompty; průběžně zaznamenat nejméně deset smysluplných commitů.
  • Připravit zveřejnění na GitHub Pages účtu Vojta-V.

Jde o shrnutí skutečných uživatelských pokynů, ne o záznam vymyšlených dalších konverzací. Text netvrdí, že žák všechny hry osobně hrál nebo je hodnotil.

Jak zadání zpřesňovat

Uveď účel webu, konkrétní stránky, vzhled, požadované chování a způsob ověření. Každou hotovou část si prohlédni a zaznamenej ji samostatným commitem.

Hraní není jen jeden žánr

Cílem webu je ukázat tři odlišné herní zážitky. Kategorie jsou jednoduché redakční rozdělení tohoto webu; jednotlivé hry obsahují i další činnosti. Web není oficiálně spojený s jejich tvůrci.
