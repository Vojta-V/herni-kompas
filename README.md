# Herní kompas

Český školní web o třech různých herních zážitcích. Samostatný projekt vytvořený s pomocí OpenAI Codex.

## Obsah

- `index.html`: magazínový úvod a tři herní směry
- `hry.html`: herní knihovna s filtrem
- `vyber.html`: interaktivní výběr podle nálady
- `zdroje.html`: oficiální zdroje, obrázky a citace AI
- `style.css`: společné responzivní styly
- `script.js`: filtr a volba nálady bez odesílání dat
- `staveni.svg`, `farma.svg`, `jeskyne.svg`: původní žánrové ilustrace

## Spuštění

Otevři `index.html`, nebo spusť `python3 -m http.server 8000` v této složce a otevři `http://localhost:8000`.
